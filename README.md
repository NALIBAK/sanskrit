# Sanskrit Learning Web App

This project is vibe coded by **Kabilan S S**.

## Project Overview

A comprehensive web application designed to help users learn Sanskrit through Tamil and English mediums. The application provides interactive tools for vocabulary, sentence building, and reading sacred texts.

## Features

### 1. Interactive Dictionary
- Searchable vocabulary list containing Nouns and Verbs.
- Translations in Tamil and English.
- "Hide Meanings" mode for self-testing.

### 2. Sentence Builder (Mixer)
- Interactive interface to construct simple Sanskrit sentences.
- Focuses on the Present Tense (Lat Lakara).
- Combines Subjects (Karta) like *Aham*, *Twam*, *Sah* with various Verbs (Kriya).
- Displays results in Sanskrit, Tamil, and English.

### 3. Sacred Texts Library
- **Principal Upanishads**: Access to texts like Isha, Kena, Katha, Mundaka, and Mandukya Upanishads.
- **Pancha Suktams**: Includes Purusha, Narayana, Sri, Bhu, and Nila Suktams.
- Features Shanti Mantras and verse-by-verse translations.

### 4. Sanskrit Varnamala (Alphabet)
- **Vowels (Swar) & Consonants (Vyanjan)**: Visual charts with pronunciation guides.
- **Gunitaakshara Builder**: A tool to mix consonants and vowels to learn syllable formation.
- **Barakhadi Chart**: A complete reference chart for all consonant-vowel combinations.

## Technologies Used
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling with CSS variables for theming (Light/Dark mode).
- **JavaScript (ES6+)**: Dynamic rendering, logic for mixers, and data handling.
